Token Radar (radar-2) ranks every rankable pre-token protocol in the sealed DefiLlama snapshot — the 40 on the watchlist plus every other pre-token protocol that is not a wrapped, staked or bridged product of a token that already trades — by an implied value whose base is the market line the snapshot's own live protocols draw (log10 market cap fitted on log10 TVL), adjusted by seven-day growth, age with no token, and chain breadth; each row carries an eight-step farm plan derived from its category, chains, TVL and age, with what each step costs and how long it takes.
